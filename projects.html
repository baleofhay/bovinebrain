Building a long-range, off-grid mesh communication network using LoRa technology. Perfect for hiking, emergency communications, and rural connectivity.

LoRa ESP32 Meshtastic MQTT

Project Highlights:

  • Range: 10+ miles line-of-sight
  • Battery life: 3-7 days on a single charge
  • Custom 3D printed enclosures
  • Integration with MQTT and Discord
  • Solar-powered repeater nodes

🎆 Wireless Fireworks Launcher

Complete

Safe, wireless fireworks ignition system with multi-channel control, safety interlocks, and remote firing capabilities.

ESP32 WiFi Relay Control Web UI

Key Features:

  • 16-channel firing control
  • Web-based interface for programming sequences
  • Safety key and arming switch
  • Continuity testing for each channel
  • 300+ foot wireless range
⚠️ Safety First: This project involves pyrotechnics and high current switching. Proper safety measures, permits, and expert knowledge required.
